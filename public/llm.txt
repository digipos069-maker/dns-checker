# DNS Checker (dnschecker.store)

> A modern, fast, and globally distributed DNS propagation and record checking tool.

## Overview
DNS Checker (https://dnschecker.store) is a free web-based utility designed for webmasters, system administrators, and developers to verify DNS records and track domain propagation across multiple global servers. 

## Capabilities
- **Global Propagation Check**: Queries domain records against over 30 distinct DNS resolvers located around the world (e.g., Google, Cloudflare, OpenDNS, Quad9, and various regional ISPs).
- **Supported Records**: A, AAAA, CNAME, MX, NS, TXT, PTR, SRV, SOA, CAA, DS, DNSKEY.
- **IP Location**: Identifies geographical data for IP addresses.
